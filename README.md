# クラベス様　技術課題

以下2つのソートアルゴリズムを実装しました。

- マージソート
- 基数ソート

## 環境構築

必要条件: Node.js v22.18以上
動作確認した環境: Node.js v26.10.0

### 実行手順

```bash
npm install
node runMergeSort.ts [任意の数値] [任意の数値] ... # マージソート
node runRadixSort.ts [任意の数値] [任意の数値] ... # 基数ソート
node runMergeSort.ts random [データ数] [最大値]   # ランダムな値でのマージソート
node runRadixSort.ts random [データ数] [最大値]   # ランダムな値での基数ソート
```

## 注意点

- どちらのソートも数値(Number)のみです。文字列には対応しておりません。
- 基数ソートについては、小数に対応しておりません
  - 小数でも桁数を揃えれば実行可能と思われますが、今回は省略しました。

## それぞれのソートの良かった点

マージソート、基数ソートを両方実装した上で、比較してよかった点を記載します。

### マージソート
- 与えられた値をそのまま使ってソートできる
  - 負の値や小数なども特に気にせずソート可能
  - 基数ソートでは0以上の整数に変換するような工夫が必要だった

### 基数ソート
- 桁数が少なく、データ量が多いほど有効である
  - データ量が多くても、桁数が少なければマージソートよりは高速になる
  - マージソートではデータ量が増えるほど分割も多くなり、計算量が増えやすい
